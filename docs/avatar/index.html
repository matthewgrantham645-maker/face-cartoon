面捕调节

以下两项只对个人校准映射生效。

二维模式使用 Mesh Avatar Studio 开源运行时，插画和表情在本地变形渲染。轻侧脸来自二维网格的透视近似，赛璐璐光影是 2.5D 法线光照；这不是完整三维重建。实际面捕和动画速度取决于设备。Live2D 对照复用原仓库的 Hiyori 示例模型，仅用于动作比较；它没有把你的插画转换成 Live2D。打开第四版对照
